# 钉钉工时分析器

一个基于 Vue 3 + Vite 开发的钉钉工时数据分析工具，支持 Excel 导入导出、工时计算、加班统计和数据可视化。

## 功能特性

- 📊 **数据导入导出**：支持导入钉钉考勤 Excel 报表，导出分析结果为 Excel 格式
- 📈 **数据可视化**：提供部门成本、考勤趋势、员工负荷等多种图表展示
- ⏱️ **工时计算**：自动计算正常工时、加班工时（时段一/时段二）、缺卡工时等
- 💰 **加班薪资**：根据配置的费率自动计算加班薪资
- 🔧 **灵活配置**：支持自定义考勤时间、加班时段、薪资费率等参数
- 📑 **多标签页**：支持同时查看多个员工的详细考勤数据

## 技术栈

- **框架**：Vue 3.5.13 + Composition API
- **构建工具**：Vite 6.0.11
- **UI 组件库**：Element Plus 2.9.1
- **表格组件**：VXE Table 4.9.6
- **图表库**：ECharts 5.5.1
- **Excel 处理**：ExcelJS 4.4.0
- **状态管理**：Pinia 2.3.1
- **路由**：Vue Router 4.5.0

## 使用说明

### 1. 导入考勤数据

- 点击「导入 Excel」按钮
- 选择钉钉考勤报表文件（.xlsx 或 .xls 格式）
- 系统会自动解析并计算工时数据

### 2. 查看数据列表

导入成功后，在数据列表中可以查看：

- 员工基本信息（姓名、部门、职位、考勤组）
- 实际总工时
- 正常工时
- 加班时段一/二工时
- 缺卡正常工时
- 净加班时段一
- 加班总薪资

### 3. 查看员工详情

点击数据列表中的「查看」按钮，会在新标签页中显示该员工的详细考勤记录。

### 4. 导出数据

点击「导出 Excel」按钮，将当前分析结果导出为 Excel 文件。

### 5. 下载模版

点击「下载模版」按钮，获取标准的考勤数据导入模版。

### 6. 全局配置

点击页面右侧的配置按钮，可以调整以下参数：

| 参数       | 说明               | 默认值   |
| -------- | ---------------- | ----- |
| 标准上班时刻   | 标准上班时间（格式：HH:mm） | 09:00 |
| 标准下班时刻   | 标准下班时间（格式：HH:mm） | 18:00 |
| 标准工时时长   | 每日标准工时（小时）       | 8     |
| 打卡去重阈值   | 连续打卡去重的时间间隔（分钟）  | 10    |
| 加班一时段起点  | 加班时段一的开始时间       | 18:00 |
| 加班一时段终点  | 加班时段一的结束时间       | 20:00 |
| 加班二时段起点  | 加班时段二的开始时间       | 20:00 |
| 加班二时段终点  | 加班时段二的结束时间       | 24:00 |
| 缺卡判定阈值   | 迟到判定阈值（格式：HH:mm） | 09:30 |
| OH1 薪资费率 | 加班时段一的时薪（元/小时）   | 50    |
| OH2 薪资费率 | 加班时段二的时薪（元/小时）   | 80    |

## 工时计算规则

### 班次划分

- 系统会自动将打卡记录按班次进行分组
- 支持跨天班次的识别和合并
- 上午打卡（12:00 前）取最早时间，下午打卡取最晚时间

### 去重规则

- 同一时段内多次打卡，在阈值时间内自动去重
- 默认去重阈值为 10 分钟

### 工时分类

1. **正常工时**：标准上班时间内的工时
2. **加班时段一（OH1）**：下班后至加班一时段终点的工时
3. **加班时段二（OH2）**：加班二时段起点之后的工时（跨天自动计算）
4. **缺卡正常工时**：晚于缺卡判定阈值打卡的工时损失

### 薪资计算

```
加班总薪资 = (净加班时段一 × OH1 费率) + (加班时段二 × OH2 费率)
净加班时段一 = max(0, 加班时段一 - 缺卡正常工时)
```

## 开发指南

### 添加新的图表类型

1. 在 `src/utils/chartOptions.js` 中定义图表配置函数
2. 在 `src/pages/Index/index.vue` 中引入并初始化图表

### 修改计算逻辑

编辑 `src/utils/calculator.js` 中的 `processEmployeeData` 函数。

### 调整默认配置

修改 `src/stores/config.ts` 中的默认配置值。

## 注意事项

- Excel 文件格式需要符合钉钉考勤报表的标准格式
- 日期范围自动从导入的文件中解析
- 配置参数会持久化存储在本地
- 支持多员工数据同时查看（通过标签页切换）
